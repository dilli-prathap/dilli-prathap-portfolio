# Dilli Prathap – Developer Portfolio

A personal portfolio website showcasing my projects, technical skills, certifications, education, and experience in software development, cloud computing, DevOps, AI/ML, and IoT.

## 🌐 Live Website

**[Visit My Portfolio](https://dilli-prathap-portfolio.netlify.app/)**

## ✨ Features

- Modern, responsive design
- Interactive animations and transitions
- Project showcase with category filters
- Technical skills and expertise
- Education and certifications
- Contact and social media links

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- React Icons

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/dilli-prathap/dilli-prathap-portfolio.git
```

Navigate to the project:

```bash
cd dilli-prathap-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
